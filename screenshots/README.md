# Portfolio screenshots

The production browser test writes five full-page captures here:

- `homepage-desktop.png` — homepage, 1440px viewport
- `projects-grid.png` — five-project index, 1440px viewport
- `coastal-house-detail.png` — project case study, 1440px viewport
- `homepage-mobile.png` — homepage, 390px viewport
- `contact-desktop.png` — enquiry page, 1440px viewport

Generate or refresh them with `npm run test:screenshots` after `npm run build`.

`homepage-cover.png` and `mobile-cover.png` are shorter crops of the homepage captures for convenient portfolio previews. Both `npm test` and `npm run test:screenshots` refresh these covers after the browser captures succeed.
