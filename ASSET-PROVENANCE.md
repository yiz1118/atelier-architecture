# Image provenance

All architecture photographs on this site are original AI-generated visual concepts made for ATELIER NORTH on 28 September 2026 with the built-in image generation tool. They do not depict built projects. Each project has a context image (`01`), spatial image (`02`) and material image (`03`). The second and third views were generated using the preceding project's image references to keep its geometry and palette coherent. Final images were reviewed visually, converted from source PNGs to local WebP files, and checked in the browser.
